# Ivi — getting started

Thank you for trying Ivi. This is an early preview, so it runs on your own computer rather than
on the web. There is nothing to install and nothing to set up: you unzip one folder and
double-click one file.

It takes about five minutes, most of which is waiting for the file to copy.

---

## 1. Unzip the folder

You have been sent a file called **Ivi-windows-amd64.zip**.

1. Save it somewhere you can find again — your **Desktop** is ideal.
2. Right-click it and choose **Extract All…**, then **Extract**.
3. You now have a folder called **Ivi**. Open it.

> **Please extract it first.** If you open the zip and double-click straight from inside it,
> Windows runs the program from a temporary place and Ivi will not remember your work.

## 2. Start Ivi

Inside the folder, double-click **Ivi**.

**The first time, Windows will try to stop you.** This is expected. It happens with any program
that has not been through Microsoft's paid registration process, and it is not a sign that
anything is wrong.

You will see a blue window saying *"Windows protected your PC"*:

1. Click **More info** — small text in the middle of the window.
2. Click **Run anyway** — a button that appears at the bottom.

You will only be asked this the first time.

If your antivirus asks something similar, allow Ivi to run. If it asks about network access,
you can safely say no: Ivi only talks to itself, on your own computer.

## 3. Wait a moment

A small window appears saying **Ivi**, then your web browser opens by itself.

The very first start takes a little longer — up to a minute — because Ivi is setting up its
database. After that it takes only a few seconds.

If your browser does not open on its own, open it yourself and go to:

**http://localhost:8080**

## While you are using it

You will find **eight example clients** already in there, with measurements going back several
months, consultation notes and diet plans. They are invented — they are there so you can see what
the software looks like with real use behind it, rather than an empty screen.

One of them, **Κώστας Μιχαηλίδης**, has nothing recorded yet, so you can see what a brand-new
client looks like.

Please do add, change and delete whatever you like. That is the point — nothing here is precious,
and you cannot break it.

### Please do not enter real client information

This is a preview running on your own laptop. It has no backups, and it is not yet covered by the
safeguards that real patient records require. Please use the invented clients, or make up new
ones.

### The small Ivi window

Keep it open while you work — it is what keeps Ivi running. It has three buttons:

- **Open Ivi** — opens the browser again if you closed the tab
- **Reset demo data** — puts the eight example clients back exactly as they started, and removes
  anything you have added. Useful if you want a clean slate.
- **Quit Ivi** — stops the program

Closing your browser tab does not stop Ivi. Use **Quit Ivi** for that.

### Coming back later

Double-click **Ivi** again. Your work is still there — it is kept on your computer between
sessions.

## If something goes wrong

**Nothing happens when I double-click.**
Give it a minute; the first start is slow. If still nothing, restart your computer and try again.

**The browser says the page cannot be reached.**
Make sure the small Ivi window is still open. If it is, try **Open Ivi** on it.

**An error window appears with a lot of technical text.**
That text is genuinely useful. Please take a screenshot, or select it and copy it, and send it
over.

**I want to remove Ivi.**
Delete the **Ivi** folder. To remove the stored data as well, press `Windows + R`, type
`%LOCALAPPDATA%`, press Enter, and delete the **Ivi** folder there too.
